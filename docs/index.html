📡 Endpoints Principales

GET /solar/activity— SILSO real
GET /analysis/correlate— Pearson + gráfico
GET /who/pandemics— Datos OMS
GET /cdc/influenza— Vigilancia CDC
GET /predict/deep-learning— LSTM
POST /graphql— GraphQL
POST /auth/login— JWT
GET /sentiment/public— Análisis

⚡ Instalación en 30 segundos

git clone https://github.com/mechmind-dwv/HelioBio-API.git
cd HelioBio-API && python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000

Luego abre http://localhost:8000/docs
